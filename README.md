# MGT 656 Software Development: LEGO City Sprint

This repository is the shared workspace for our LEGO City Scrum sprint.

## Sprint goal

Build a connected LEGO city with a main road, civic services, public spaces,
and neighborhood details. We manage the work as user stories on the shared
Kanban board.

## Team workflow

1. Pull the latest `main` before starting work.
2. Create a focused branch, such as `feature/fire-station`.
3. Commit clear, small changes and push the branch.
4. Open a pull request for a teammate to review before merging into `main`.

## Project board

The interactive sprint board lives in Codex Canvas and includes our initial
stories, estimates, and build sequence.
